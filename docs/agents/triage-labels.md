# Triage labels

Canonical roles map directly to these GitHub labels:

| Role / label | Meaning |
| --- | --- |
| needs-triage | Maintainer needs to evaluate |
| needs-info | Waiting on reporter for more information |
| ready-for-agent | Fully specified for independent agent implementation |
| ready-for-human | Requires human implementation |
| wontfix | Will not be actioned |

When a skill mentions a role, use its matching label.
